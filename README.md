# ЕнергоКампус

Сайт студентської ініціативи з енергоефективності КПІ ім. Ігоря Сікорського
(на базі досвіду програми UDEPP). Next.js (App Router) + TypeScript + Tailwind CSS v4.

## Розробка

```bash
npm install
npm run dev
```

Сайт буде доступний на http://localhost:3000.

## Структура

- `/` — головна (hero, звернення про проблему, банк ідей, цінності, новини)
- `/news`, `/news/[slug]` — новини зі списком, фільтром за категорією, пошуком
- `/about` — про проєкт, місію, UDEPP, дорожню карту, команду, партнерів
- `/tips` — поради з енергозбереження, міфи, навчальні матеріали
- `/stats` — статистика, графіки (recharts), рейтинг по корпусах, аудити
- `/contacts` — контакти, форма зворотного зв'язку, FAQ
- `/report` — резервна веб-форма (дублює функціонал Telegram-бота)

Усі тексти й цифри в `src/lib/data.ts` — це заглушки для макета. Заміни їх
на реальний контент чи підключи до API/бота, коли дані будуть готові.

## Деплой на Vercel

1. Заливаєш репозиторій на GitHub.
2. На vercel.com → **Add New Project** → обираєш репозиторій.
3. Vercel сам розпізнає Next.js — жодних додаткових налаштувань білду не потрібно
   (Build Command: `next build`, Output: `.next`).
4. Тисни **Deploy**.

Або через CLI:

```bash
npm i -g vercel
vercel
```
